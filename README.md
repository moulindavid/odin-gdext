# Odin bindings for Godot 4

***godot-odin*** is a library to intergrate Odin with Godot 4. 

[Godot](https://godotengine.org/) is an open-source game engine, focusing on a productive and batteries-included 2D and 3D experience.  
Its _GDExtension_ API allows integrating third-party languages and libraries.
